# Gesher and Apple's public APIs

Every Gesher tool, and whether a third-party app could do the same job through a documented public Apple API on macOS. Apple's documentation was checked on 15 November 2026.

**How to read "Public alternative":**
- **yes:** a public API does the whole job.
- **partial:** a public API does part of it, or the caller has to compute the result.
- **no:** no public framework does it. Scripting dictionaries (AppleScript) aren't counted.

**Why Gesher uses the private frameworks even where a public one exists:** some of what Gesher does isn't in the public APIs at all, and in my use the private frameworks the apps themselves use were faster. I haven't benchmarked that yet.

"Gesher's class" is how the tool works today: **private** means it uses only the frameworks the app itself uses; **mixed** means a public API does part of the job (for example vCard, image metadata, reading a store copy with SQLite, or launching Freeform).
