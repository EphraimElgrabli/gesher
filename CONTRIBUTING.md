# Contributing

Thank you for your interest. Gesher is published as a finished experiment and is **not accepting
contributions**: pull requests and issues are closed, and there is no support.

You are very welcome to fork it. The GPL-3.0 lets you change it and share your version, as long as you
keep it under the same license. To get started in a fork:

- [AGENTS.md](AGENTS.md): the rules, the operation pattern every app follows, and the checklist for
  adding an app. It is written for both people and coding agents.
- [docs/architecture.md](docs/architecture.md): how the pieces fit together.
- `make check`: lint, tests and a release build. It must pass on every commit.

Security problems: see [SECURITY.md](SECURITY.md).
